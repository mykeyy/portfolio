This is a placeholder and a guide. Drafts show while you run `bun run dev` and never appear in a build. Each research piece is one `.mdx` file in `src/content/writing`, with `kind: research` at the top. [MDX](https://mdxjs.com/docs/what-is-mdx/) is Markdown that can hold components like charts. Short notes use `kind: note` and plain `.md`.

## Start with the question

The summary at the top is the first thing anyone reads, here and in the ledger, so write it as the question you looked into or the answer you found. Put the answer early. People who only read the first paragraph should still leave with it.

A piece with two or more `##` sections gets a contents list. On a wide screen it stays beside the text while you read, and it marks the section you are in.

## Charts

Write `<Chart>` anywhere in an `.mdx` file. It is drawn when the site builds, so it costs the reader no JavaScript to see, and every chart keeps its numbers in a table under **Show the data**.

A line chart takes up to three series. The site has two colors, so lines are told apart by style: solid, dashed, dotted. Hover or tap the chart to read each point, or tab to it and use the arrow keys.

<Chart
  kind="line"
  title="Three made-up series, 2019 to 2026"
  sample
  xLabel="Year"
  unit="%"
  series={[
    { name: "Alpha", data: [[2019, 12], [2020, 18], [2021, 21], [2022, 30], [2023, 34], [2024, 41], [2025, 47], [2026, 55]] },
    { name: "Beta", data: [[2019, 30], [2020, 28], [2021, 31], [2022, 27], [2023, 25], [2024, 26], [2025, 22], [2026, 19]] },
    { name: "Gamma", data: [[2019, 5], [2020, 7], [2021, 6], [2022, 9], [2023, 12], [2024, 11], [2025, 10], [2026, 8]] },
  ]}
/>

A bar chart compares amounts, with each value at the tip of its bar. These numbers are real: the files the coming-soon page downloads.

<Chart
  kind="bar"
  title="What the coming-soon page downloads, in kilobytes"
  source="the myky.cc repository, October 2026"
  unit=" KB"
  bars={[
    { label: "Page (HTML, CSS, JS)", value: 40.8 },
    { label: "Anton font", value: 18.6 },
    { label: "Roboto Mono font", value: 12.7 },
  ]}
/>

The code for the first chart looks like this:

```mdx
<Chart
  kind="line"
  title="Three made-up series, 2019 to 2026"
  sample
  xLabel="Year"
  unit="%"
  series={[
    { name: "Alpha", data: [[2019, 12], [2020, 18]] },
    { name: "Beta", data: [[2019, 30], [2020, 28]] },
  ]}
/>
```

Leave out `sample` once the numbers are real, and add `source` so readers know where they came from.

## Tables, quotes, and footnotes

Tables are for exact numbers people will compare across a row.

> A pull quote sits a size up from the text, for the one line you want people to remember.

Footnotes go at the bottom, where they don't interrupt the reading.[^1]

[^1]: Write `[^1]` in the text and `[^1]: the note` anywhere below it.
